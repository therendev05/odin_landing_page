# Landing Page - The Odin Project

### Description
This project is part of "The Odin Project Foundations Curriculum".
The goal was to build a visually appealing landing page based on a provided example, putting into practice the HTML and CSS skills acquired.



### What I Learned
By completing this project, I have strengthened my web design foundations:

- Flexbox Mastery: I improved my use of Flexbox, gaining a deeper understanding of how to align elements.

- Layout Structuring: I learned how to clearly present information to the user by organizing everything in containers.



### Technologies Used
- HTML
- CSS (Flexbox)
